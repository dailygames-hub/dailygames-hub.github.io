Informativa sulla privacy

Ultimo aggiornamento: 27 settembre 2026

Questa informativa riguarda il sito dailygames-hub.github.io e i giochi che ospita (per esempio DOTTO). Il sito è un progetto personale senza scopo di lucro gestito da Luca Zanotto, raggiungibile tramite la pagina github.com/dailygames-hub.

QUALI DATI RACCOGLIAMO

Nessuno. Il sito non richiede registrazione, non ha moduli da compilare e non raccoglie dati personali. Non usiamo strumenti di analisi del traffico né cookie di profilazione.

DATI SALVATI SUL TUO DISPOSITIVO

I giochi salvano progressi, statistiche e impostazioni (per esempio la lingua scelta) nella memoria locale del tuo browser (localStorage). Questi dati restano sul tuo dispositivo, non vengono inviati a nessun server e puoi cancellarli in qualsiasi momento eliminando i dati di navigazione del sito dal browser.

HOSTING

Il sito è ospitato da GitHub Pages, un servizio di GitHub, Inc. Come ogni servizio di hosting, GitHub può registrare dati tecnici delle richieste, come l'indirizzo IP, per motivi di sicurezza e funzionamento. Per i dettagli vedi l'informativa sulla privacy di GitHub.

CONTATTI

Per qualsiasi domanda su questa informativa puoi scrivere tramite la pagina github.com/dailygames-hub.

Privacy policy (English)

Last updated: 27 September 2026

This notice covers dailygames-hub.github.io and the games it hosts (for example DOTTO). The site is a personal, non-commercial project run by Luca Zanotto, reachable through github.com/dailygames-hub.

WHAT WE COLLECT

Nothing. The site has no sign-up, no forms and collects no personal data. We use no analytics tools and no tracking cookies.

DATA STORED ON YOUR DEVICE

The games save progress, statistics and settings (such as your chosen language) in your browser's local storage. This data stays on your device, is never sent to a server, and can be deleted at any time by clearing the site's browsing data in your browser.

HOSTING

The site is hosted on GitHub Pages, a service of GitHub, Inc. Like any hosting provider, GitHub may log technical request data such as IP addresses for security and operational reasons. See the GitHub Privacy Statement.

CONTACT

For any question about this notice, get in touch through github.com/dailygames-hub.
