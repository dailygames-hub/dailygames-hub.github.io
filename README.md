# Daily Games Hub

Landing page di [dailygames-hub.github.io](https://dailygames-hub.github.io): piccoli giochi gratuiti da browser, uno nuovo ogni giorno.

I giochi vivono ciascuno nel proprio repository dell'organizzazione e vengono pubblicati come sottocartelle del sito radice (per esempio `/dotto`).

## File

- `index.html`: la landing page (IT/EN)
- `privacy.html`: informativa sulla privacy, con una sezione già pronta da attivare quando saranno presenti annunci
- `favicon.svg`, `fonts/`: icona e carattere Big Shoulders (SIL OFL)

## Aggiungere un gioco

Aggiungi un blocco `<a class="game" href="nome-gioco/">` in `index.html` e le relative stringhe in `T.it` e `T.en`.
